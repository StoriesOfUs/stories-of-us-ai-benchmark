# Stories Of Us CPU Dependency Smoke Test V01

Experimental dependency-only package. It installs the exact frozen CPU wheel set, checks imports and storage, and stops. It downloads no model/tokenizer and performs no model loading or inference.

**EXPERIMENTAL — NOT PRODUCTION APPROVAL**

- manual `workflow_dispatch` only;
- one run, zero retries;
- standard public GitHub CPU runner;
- 15-minute job cap;
- £0 maximum;
- model/tokenizer downloads: zero;
- model computations and evaluation cases: zero.

Execution remains governed by the frozen manifest, separate owner-authority record and one-use lock.
