# stories-of-us-ai-benchmark
Experimental AI summary-writing benchmark for Stories Of Us.

This public repository contains a manual, test-only CPU benchmark. It does not
contain the Stories Of Us website, protected curated corpus or operational AI
Agent.

See [BENCHMARK.md](BENCHMARK.md) for the model, safety and execution details.

All generated summaries are experimental, are not editorially approved and
must not be used for Stories Of Us publication.
